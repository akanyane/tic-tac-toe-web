# Tic-Tac-Toe

A polished, browser-based tic-tac-toe against the computer — plain HTML, CSS and JavaScript, no build step.

## Features

- **Three difficulty levels** — Easy (random), Medium (mixed) and Impossible (minimax, never loses)
- **Alternating starter** — you and the computer take turns opening each round
- **Persistent score** — saved in `localStorage`
- **Keyboard support** — `1`–`9` to play, `R` to restart
- **Motion & effects** — aurora background, starfield, split/shiny text, spotlight cards,
  3D tilt board, animated SVG marks, win line, click sparks, confetti and magnetic buttons
- Respects `prefers-reduced-motion`

## Running

Open `index.html` in a browser. That's it.
